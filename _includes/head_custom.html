{%- comment -%} Language switcher (EN / 中文) + preference-based routing. Preference key `routero.lang` mirrors the main site's convention (routero.dcsmartvision.com i18n.js). NOTE: localStorage is origin-scoped, so the docs origin cannot read a value written by the main site — as a cross-subdomain fallback we also accept a `routero.lang` cookie on the parent domain (if the main site ever starts writing one, subdomains sync for free). The main site stores 'zh'; we accept 'zh' / 'zh-CN' and write 'zh-CN'. Resolution order on every page: 1. localStorage routero.lang → 2. parent-domain cookie routero.lang → 3. browser language (navigator.languages), persisted on first resolve. If the resolved language does not match the page being viewed, redirect to the same page in the other language (location.replace — no history entry). Manual switcher clicks persist the choice and win from then on. Switcher pairs pages by URL suffix: English at /, Chinese at /zh-CN/. Done in JS to sidestep jekyll-polyglot's automatic URL relativization, which would otherwise rewrite a hard-coded English link to the active language. {%- endcomment -%}
